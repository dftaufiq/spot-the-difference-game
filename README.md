Lanternlight is a cozy spot-the-difference game: three hand-drawn scenes (a dusk market, a coral reef, a snowy cabin), 21 hidden differences, hints, combos, a timer and keyboard play — all static files, no network needed.

## Run it

```sh
node serve.mjs
```

Then open http://localhost:8080 in a desktop browser.
